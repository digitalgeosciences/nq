# Agent Guidelines

## Core Principles & Safety

- Do not act or modify files without explicit user permission.
- Do not commit or push without explicit user permission.
- Clarify ambiguous requirements before getting started.
- Keep responses concise, direct to the point, and token-efficient.

## Project Stack & Standards

- **Framework**: TanStack Start / React 19 / Vite.
- **Styling**: Tailwind CSS v4 / Radix UI / Motion.
- **Language**: TypeScript (strict types, avoid `any`).
- **State & Routing**: TanStack Router & TanStack Query.

## Development & Quality Checks

- Validate changes with linting and type checks (`npm run lint`, `npm run build:dev`).
- Maintain formatting standards (`npm run format`).
- Do not modify routing definitions or server functions without user review.
